# Pedalboard texture draft

The maintainer supplied `assets/ui/textures/pedal-board-texture-v01.jpeg`, generated
with Gemini Nano Banana through a personal Gmail account from an assistant-provided
prompt. On 2026-10-20 the maintainer approved using it as a replaceable draft for the
practice-board interface. No claim of exclusive copyright is made. The source image
remains unchanged and gitignored.

The runtime copy `pedal-board-texture-v01.jpeg` is resized to 1024x1024 and saved at
JPEG quality 82 for embedding in the practice-board GUI. It is a visual background
only. It does not contain pedal controls or labels. Replace or regenerate it if it
does not read well behind the real plugin editors.
